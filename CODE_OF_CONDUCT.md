# Code of conduct

Be kind and be useful. We want this project to be welcoming to everyone, whatever their background or experience.

- Be respectful. Disagree with ideas, not people.
- Assume good faith; ask before assuming bad intent.
- No harassment, discrimination, or personal attacks, in any form.
- Keep discussion focused on making the project better.

Maintainers may remove comments, close issues, or block people who break these rules. To report a problem, contact the maintainers through a private GitHub security advisory or the email on the maintainer's GitHub profile.

This document is intentionally short; the spirit follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
